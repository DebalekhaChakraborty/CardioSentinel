# CardioSentinel — Journal Extension

```text
CardioSentinel
|
+-- V1
|   completed frozen evidence programme
|   immutable historical scientific record
|
+-- Journal Extension / V2
    prospective top-journal research programme
    nothing here has been measured yet
```

**V1 is preserved and remains authoritative for what V1 measured.** It is not
discarded, replaced, cleaned up or reinterpreted by anything in this directory.
V2 exists to resolve limitations V1 revealed, not to overwrite them.

**V2 does not supersede V1 evidence.** It may be *motivated* by V1 findings — its
negative results, its hypotheses, its stated limitations — and it may reuse V1
implementations. It may not present consumed V1 VALIDATION or TEST evidence as
fresh V2 confirmation. All fifteen V1 one-shot budgets are spent; the B4 neural
sealed test, the last of them, was consumed on 2026-08-25 and is structurally
closed.

**No file in this directory authorizes an experiment by existing.** Not the
blueprint, not the charter, not the ledger, not a row in a table, not a mention
in source code or an issue. Scientific work follows:

```text
QUESTION -> PROTOCOL -> PRE-REGISTRATION -> AUTHORIZATION -> EXECUTION -> REPORT / DECISION
```

The blueprint is the **programme planning authority**: it says what the
programme is for and in what order it should be approached. Execution authority
comes only from experiment-specific frozen documents — a protocol, its
pre-registration, and an explicit human authorization naming an attempt budget.
