# Checksum manifest

**The digests live in [`DEMO_BUNDLE_SELECTION.json`](DEMO_BUNDLE_SELECTION.json)**,
generated by `scripts/provenance/select_demo_bundle.py` and checked by
`verify_reproducibility.py`. They are not restated here, because a second
hand-maintained copy would drift from the first.

```bash
python reproducibility/verify_reproducibility.py    # exits non-zero on drift
```

## Scope

**Covered:** the 27 files of the demo bundle, 1.63 MiB, each with its SHA-256,
byte size, source path and the loader that reads it.

**Not covered:** the research tier — `cardiosentinel-runs/`,
`cardiosentinel-features/`, `cardiosentinel-data/`. These are gitignored, not
distributed, and carry their own manifests and experiment locks.

**External mirror: not verified.** An S3 mirror of the evidence tree exists. As
of 2026-08-23 the session had expired and it could not be re-verified. Its state
is *not verified*, which is neither *verified* nor *lost*.

**Nothing in this package depends on that mirror.** Evidence preservation uses
cryptographic manifests; external mirrors are optional. A reproducibility claim
that depends on something unverifiable is not a reproducibility claim.
